# AI Nugget 0.7.2

TypeScript consumers on classic `node10` module resolution (the default for
`module: commonjs`) can now resolve the `@jxburros/ai-nugget/agent` types: a
`typesVersions` entry maps the subpath, and the packaging integration check
type-checks root and `/agent` imports under `node10`, `node16` (ESM) and
`bundler`.

Documentation only otherwise: the JX Runtime guidance is updated for JX 1.5
(error body shape, keys required from allow-listed browser origins, and the
`providerOptions.stream_options` opt-in for real streamed token counts), and
stale links and version notes are corrected. No runtime behavior changed. No
registry publication is performed here.
