# AI Nugget 0.7.6

Release-pipeline change only; the package contents are identical to 0.7.5.
The npm publish job now authenticates with npm trusted publishing (GitHub
Actions OIDC) instead of the `NPM_TOKEN` access token, which expires on
2026-11-08. The job already requested `id-token: write` and runs Node 24
(npm 11), so the only workflow change is dropping `NODE_AUTH_TOKEN` from the
npm publish step. Provenance is still attached. GitHub Packages publishing is
unchanged.

Before releasing, add GitHub Actions as a trusted publisher for
`@jxburros/ai-nugget` on npmjs.com (repository `jxburros/AI-Nugget`, workflow
`publish.yml`, with `npm publish` allowed).
