# AI Nugget 0.7.3

Release-pipeline fix only; the package contents are identical to 0.7.2. The
Release workflow's publish steps passed the packed tarball to `npm publish` as
`package-output/<name>.tgz`, which npm 11 reads as a GitHub `owner/repo`
shorthand and tries to clone over SSH, so 0.7.1 and 0.7.2 never reached npm or
GitHub Packages. The path now carries a `./` prefix. This is the first release
since 0.7.0 to publish, so it carries the 0.7.1 Anthropic fixes and the 0.7.2
`/agent` types fix.
