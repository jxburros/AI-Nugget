# AI-Nugget 0.7.5

Adds MiniMax, Z.AI, DashScope, Hugging Face, DeepInfra, SambaNova, NVIDIA NIM,
Cloudflare Workers AI, AWS Bedrock, Vertex and Azure OpenAI v1 profiles.
Responses and native Bedrock Converse are explicit protocol choices. Cloud
coordinates, refreshable KeySource credentials and optional request signing
keep cloud SDKs outside the dependency-free core. New compatible profiles
preserve assistant reasoning/tool state for replay.

Includes handler-level Node/browser contracts, an executable QAI-ality profile,
a configurable manual live-smoke job, honest verification documentation and a
proposed plan for optional media/document/retrieval operations. No live provider
validation or package publication was performed during implementation.
