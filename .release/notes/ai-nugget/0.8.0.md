# AI-Nugget 0.8.0

**Perplexity users, read before updating:** the `perplexity` profile now targets
Perplexity's Orchestrator API (`https://api.perplexity.ai/orchestrator/v1`)
because Sonar Chat Completions support ended on 2026-09-27. It takes catalog
model IDs such as `perplexity/sonar`. To keep the old endpoint, set
`baseUrl: 'https://api.perplexity.ai'` on the connection. `usage.inputTokens`
now includes cached prompt tokens for Anthropic and Bedrock Converse too. See
UPGRADING.md.

New: Meta Model API (`meta`), Vercel AI Gateway (`vercel`) and Open Responses
(`open-responses`) profiles; audio/video/file input parts and in-band media
output; `xhigh`/`max` reasoning effort with Gemini 3 thinking levels and
thought-signature replay; portable prompt caching with cached-token usage;
rate-limit header parsing for backoff and telemetry; Standard JSON Schema for
`chatParsed` and `defineTool({ input })`; provider-hosted MCP servers governed
through `KeySource` and `checkMcpServer`. Moonshot, DeepSeek, Together,
Fireworks, Groq and MiniMax profiles were refreshed against current docs.

All provider changes are covered by mocked Node and Chromium contract tests;
no live provider validation was performed for this release.
